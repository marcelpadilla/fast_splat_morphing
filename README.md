Supplementary material for the preprint **Fast Splat Morphing**. FSM morphs one 3D Gaussian splatting capture into another through a near-optimal bijective assignment between their splats, built in the browser in well under two seconds for a million splats.

Pick two objects and the assignment between them is computed live, in your browser:

```bash
python demo/serve.py        # http://127.0.0.1:8000/
```

There is also a no-server version: **double-click `OPEN_ME.html`**. It is the same page with the four splats and the worker bundled under `offline/`, so it opens from `file://` and runs with nothing installed. The base64 payloads are decoded in a worker, off the page's thread, so picking an object never freezes the view. `offline/build_offline.py` regenerates the bundle if the splats or the worker change.

`demo/pairings.js` is the method, the co-bisection that builds the assignment. `demo/cloud.js` prepares the two clouds (outlier cull, normalization, padding the smaller side with transparent clones) and `demo/trajectories.js` bends each pair's path; `demo/renderer.js` is the viewer, adapted from [antimatter15/splat](https://github.com/antimatter15/splat) (MIT). `cloud.js`, `pairings.js` and `trajectories.js` are the files the paper's timings were measured with, unchanged. The time the demo shows covers the same step the paper times: packing both clouds and building the assignment, single-threaded.
